# Student Assessment Form

Use these fields in the Google Form:

1. Student name
2. Age
3. Country
4. Current Qur'an level
5. Previous Qur'an education
6. Current difficulty
7. Goal
8. Preferred class schedule
9. Parent contact
10. Preferred language

## Live Assessment
Assess:
- Reading
- Makharij
- Tajweed
- Fluency
- Memorization

## Placement Statement
“Based on the assessment, we recommend **[Level/Program]**.”

Record the evidence behind the recommendation in the student profile.
