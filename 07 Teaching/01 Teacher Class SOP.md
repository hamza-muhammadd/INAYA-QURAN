# Teacher / Class SOP

## Before Class
- Review student profile and last feedback.
- Know today's target.
- Prepare the relevant material.

## During Class
1. Greet and settle the student.
2. Review previous target.
3. Listen before correcting.
4. Teach one clear concept/skill at a time.
5. Correct priority errors precisely and kindly.
6. Have the student repeat/apply the correction.
7. Assign realistic practice.

## After Class
Record:
- What was covered
- Main strength
- Main weakness
- Practice/homework
- Next target

## Weekly
Review progress and flag students who need support.

## Monthly
Assess readiness and update the parent-facing progress summary.

## Hifz
Track Sabak (new lesson), Sabqi (recent revision), and Manzil (longer-term revision). Protect retention before increasing memorization load.
