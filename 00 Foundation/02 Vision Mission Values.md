# Vision, Mission & Core Values

## Vision
To grow into a trusted Qur'an learning institution known for sound teaching, disciplined learning systems, strong character, and measurable student progress.

## Mission
Inaya provides structured Qur'an education through assessment, personalized learning plans, consistent teaching, practice, feedback, and progress review.

## Core Values
1. Qur'an-centered learning
2. Correctness before speed
3. Excellence with ihsan
4. Compassion and respect
5. Consistency and discipline
6. Honest assessment
7. Lifelong learning
