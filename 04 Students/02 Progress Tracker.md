# Student Progress Tracker

## Weekly Record
- Attendance
- Lesson/module completed
- Practice/homework
- Main strength
- Main weakness
- Teacher feedback
- Next target

## Monthly Record
- Assessment date
- Reading result
- Tajweed result
- Fluency result
- Memorization result where relevant
- Overall status: On Track / Needs Support / Ready
- Parent communication completed
- Intervention plan if needed

Progress records should be factual, concise, and useful for the next teacher/lesson.
