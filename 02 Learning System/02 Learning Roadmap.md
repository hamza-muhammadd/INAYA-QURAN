# Learning Roadmap

## Foundation
Qaida + Arabic letters + basic reading.

**Ready to progress when:** student recognizes letters, joins letters, reads basic words, and demonstrates foundational pronunciation.

## Quran Reading
Fluency + pronunciation + basic Tajweed.

**Ready to progress when:** reading is sufficiently accurate and increasingly fluent for the student's level.

## Tajweed
Rules + Makharij + Sifaat + application.

**Ready to progress when:** core rules are understood and applied during live recitation with decreasing correction.

## Advanced Recitation
Fluency + accuracy + Waqf/Ibtida + recitation development.

**Ready to progress when:** student demonstrates stable, accurate and confident recitation with appropriate stopping/starting awareness.

## Hifz
Memorization + Sabak + Sabqi + Manzil + revision.

**Ready to progress when:** memorization quality and revision discipline are stable enough for sustainable advancement.

### Important
Hifz is a program pathway, not an automatic reward for completing Tajweed. Placement depends on assessment, readiness, goals, schedule, and teacher recommendation.
